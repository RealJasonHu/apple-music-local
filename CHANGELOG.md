# Changelog

## 2.0.0 — first public release

- Native macOS interface with Apple sign-in and local session persistence.
- Online subscription checks and catalog-region-aware song, album, and playlist search.
- Search pagination, multiple selection, and direct-to-queue downloads.
- Batch share-link input; MP3, WAV, or original AAC output; configurable destination.
- Stop, retry, progress, persisted history, and Finder reveal.
- Guards against stale authentication callbacks, logout/download races, mixed-region search pages, and overwriting prior output.
- Standalone application packaging with pinned dependency bootstrap, original icon artwork, and synthetic regression tests.

This public release preserves the v2.0 application behavior. Release packaging and dependency provenance are prepared separately from the earlier local install.
